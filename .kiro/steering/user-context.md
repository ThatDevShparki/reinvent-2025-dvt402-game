# User Game Preferences

## Project: Kiro-themed Pokemon-style Adventure Game

### Technical Stack

- TypeScript + HTML5 Canvas
- 32x32 pixel art sprites
- 8-bit color scheme with Kiro purple overlay

### Gameplay

- Top-down, isometric JRPG-style map
- 4-directional movement with fluid physics (acceleration, friction, max speed)
- No gravity (flat plane movement)
- Adventure-focused (no scoring system initially)

### Character

- Ash-inspired character dressed in Kiro-themed clothing
- Player sprite with directional animations

### Map Design

- Medium-sized map
- Starter town setting
- Patches of grass (non-obstructive, walkable)
- Trees (obstructive, form barriers and maze-like exploration areas)
- Edge scrolling camera system

### Visual Style

- Pixel art aesthetic
- 8-bit color palette
- Kiro purple (#790ECB) as accent/overlay color
- Dark theme base (black-900, prey-750 for UI elements)

### Core Features (Phase 1)

- Smooth character movement with physics
- Collision detection with environment props
- Camera following player with edge scrolling
- Start and restart functionality
