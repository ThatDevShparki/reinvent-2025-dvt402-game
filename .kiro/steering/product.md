# Product Overview

Kiro Adventure is a Pokemon-style top-down adventure game built for the AWS re:Invent 2025 DVT402 workshop.

The game features:

- Ash-inspired character in Kiro-themed clothing
- Top-down JRPG-style exploration with 4-directional movement
- Pixel art aesthetic (32x32 sprites, 8-bit color palette)
- Starter town setting with grass patches and tree obstacles
- Smooth physics-based movement (acceleration, friction, collision detection)
- Edge-scrolling camera system that follows the player

The game emphasizes adventure and exploration over scoring, with a retro pixel art style enhanced by Kiro's signature purple (#790ECB) branding.
